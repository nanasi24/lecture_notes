# 復習ノート生成

引数: `$ARGUMENTS`(形式: `<バージョン> <PDFパス> [出力パス]`)

1. 第1引数がバージョン(`v0`〜`v3`)。省略時は最新の実装済みバージョンを使う。
2. `.claude/skills/review-notes/versions/<バージョン>.md` **だけ**を読み、その手順に従う
   (他のバージョンのファイルは読まない。ベンチマークの公平性のため)。
3. 出力形式は `.claude/skills/review-notes/template.md` に従う。
4. 出力パスが無ければ `notes/<PDF名>.md` に書く。中間ファイルは `work/<PDF名>/` に置く。
5. 書き終えたら、出力パスとトピック数・用語数・問題数だけを1行で報告する(ノート本文は表示しない)。

実装済みバージョン: v0, v1, v2

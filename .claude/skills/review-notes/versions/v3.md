# v3: 章ごとにサブエージェント(Haiku)へ委譲 → メイン(Sonnet)で統合・問題作成

PDF 本体もチャンクの原文も、メインでは読まない。

1. ノイズ除去と章分割(`<PDF名>` は拡張子なしのファイル名):
   `.venv/bin/python .claude/skills/review-notes/extract.py <PDFパス> --out work/<PDF名> --split`
   コマンドの出力(JSON)の `pages` がページ数。
2. **15 ページ以下** の短い資料なら、サブエージェントは使わず `work/<PDF名>/pages.txt` を Read で1回読み、手順 4 へ。
3. **15 ページ超** なら、`work/<PDF名>/manifest.json` を読み、`chunks` の全チャンクについて
   `chunk-summarizer` サブエージェントを **1つのメッセージでまとめて同時に** 起動する。
   各サブエージェントへの指示は「チャンク <番号>(p.<開始>-<終了>): <チャンクファイルのパス> を要約して」だけでよい。
   返ってきた要約だけを材料にする(要約をファイルに書き出したり、チャンクを読み直したりしない)。
4. `.claude/skills/review-notes/template.md` の形式でノートを書き、出力パスに保存する。
   要点の統合と確認問題の作成はメインが行う。各項目に (p.N) を付ける。

# v2: ノイズ除去 + 章単位で要点抽出 → 統合

PDF 本体は読まない。

1. 次のコマンドでノイズ除去と章分割を行う(`<PDF名>` は拡張子なしのファイル名):
   `.venv/bin/python .claude/skills/review-notes/extract.py <PDFパス> --out work/<PDF名> --split`
   毎ページのヘッダー/フッター/ページ番号、重複タイトル、重複ページ(「p.N と同内容」)は除去済み。
2. `work/<PDF名>/manifest.json` を読み、`chunks` に並んだチャンクを順番に処理する。チャンクごとに:
   - Read でそのチャンクのファイルを読む(各ページは `--- p.N ---` で始まる)
   - そのチャンクの要点・重要用語(日本語と英語の両表記)・出題できそうな点を、根拠ページ (p.N) 付きの
     短い箇条書きにまとめ、`work/<PDF名>/points/chunk_NN.md` に書く(NN はチャンク番号)
3. 全チャンクの要点がそろったら、要点だけを材料に `.claude/skills/review-notes/template.md` の形式で
   ノートを統合して出力パスに保存する。チャンクの原文は読み直さない。各項目に (p.N) を付ける。

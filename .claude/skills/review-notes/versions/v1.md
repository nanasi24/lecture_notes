# v1: PDF を事前にテキスト化してから読ませる

PDF を直接読まない(ページ画像が文脈に入るのを避ける)。ノイズ除去はまだしない。

1. 次のコマンドでテキスト化する(`<PDF名>` は拡張子なしのファイル名):
   `.venv/bin/python .claude/skills/review-notes/extract.py <PDFパス> --out work/<PDF名> --raw`
2. Read ツールで `work/<PDF名>/pages.txt` を1回で読む。各ページは `--- p.N ---` で始まるので、これを根拠ページ番号に使う。
   PDF 本体は読まない。
3. `.claude/skills/review-notes/template.md` の形式でノートを書き、出力パスに保存する。各項目に (p.N) を付ける。

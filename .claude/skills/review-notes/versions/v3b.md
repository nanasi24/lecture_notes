# v3b: v3 の改良版。サブエージェントを 3 つにまとめて待機ターンを減らす

v3 ではチャンク 7 つに 1 つずつサブエージェントを起動したため、サブエージェントが終わるたびにメインの
呼び出しが増えることがあった。v3b ではチャンクを 3 グループにまとめ、起動数と読むファイルを減らす。
PDF 本体もチャンクの原文も、メインでは読まない。

1. ノイズ除去・章分割・グループ化(`<PDF名>` は拡張子なしのファイル名):
   `.venv/bin/python .claude/skills/review-notes/extract.py <PDFパス> --out work/<PDF名> --split --groups 3`
   出力(JSON)に `pages`(ページ数)と `groups`(各グループのファイル一覧とページ範囲)が含まれる。
   manifest.json は読まない(必要な情報はこの出力にある)。
2. **15 ページ以下** なら、サブエージェントは使わず `work/<PDF名>/pages.txt` を Read で1回読み、手順 4 へ。
3. **15 ページ超** なら、`groups` の各グループについて `chunk-summarizer` サブエージェントを
   **1つのメッセージでまとめて同時に** 起動する。指示は「p.<開始>-<終了> の次のファイルを要約して: <ファイル一覧>」だけでよい。
   全員の要約がそろうまで、途中経過のメッセージは書かない。要約だけを材料にする(書き出し・読み直しはしない)。
4. `.claude/skills/review-notes/template.md` の形式でノートを書き、出力パスに保存する。
   要点の統合と確認問題の作成はメインが行う。各項目に (p.N) を付ける。
